### Changes Summary - Space Invaders Project

This document outlines the modifications and additions made to the project to incorporate Behavioral Design Patterns (State and Strategy) without disrupting the existing Structural Design Patterns.

#### 1. New Packages and Files (State Pattern)
Location: `src/main/java/behavioral/state/`

*   **`GameState.java`**: Interface defining the contract for game states (`handleInput()`, `update()`).
*   **`GameBehavior.java`**: New Interface defining the contract for the context (Board) to expose game logic methods (`cycle()`, `gameOverLogic()`) to the states.
*   **`MenuState.java`**: Concrete state representing the game menu.
*   **`PlayingState.java`**: Concrete state representing the active gameplay. **FUNCTIONAL INTEGRATION**: Now holds a reference to `GameBehavior` and delegates `update()` calls to `behavior.cycle()` (the main game animation).
*   **`PauseState.java`**: Concrete state representing the game paused.
*   **`GameOverState.java`**: Concrete state representing the game over screen. **FUNCTIONAL INTEGRATION**: Now holds a reference to `GameBehavior` and delegates `update()` calls to `behavior.gameOverLogic()`.
*   **`StateManager.java`**: Context class to manage the current state and transition between them.

#### 2. New Packages and Files (Strategy Pattern)
Location: `src/main/java/behavioral/strategy/`

*   **`Movable.java`**: Interface defining objects that have coordinates (`getX`, `setX`, etc.).
*   **`MovementStrategy.java`**: Interface defining the strategy method `move(Movable entity, int direction)`.
*   **`StraightMovement.java`**: Concrete strategy implementing simple horizontal movement.
*   **`ZigZagMovement.java`**: Concrete strategy implementing a wave-like movement pattern.

#### 3. Modified Existing Files
*   **`src/main/java/Alien.java`**:
    *   **Implemented Interface**: Now implements `Movable`.
    *   **Strategy Integration**: Added `MovementStrategy` field and logic in `act()` to delegate movement to the strategy.

*   **`src/main/java/Board.java`**:
    *   **Implemented Interface**: Now implements `GameBehavior` to allow States to call back into the game logic.
    *   **State Integration**: Added `StateManager` instance.
    *   **Refactored Logic**: The main game loop (`run()`) no longer calls `animationCycle()` directly. Instead, it calls `stateManager.update()`.
    *   **Flow**: `Board.run()` -> `StateManager.update()` -> `PlayingState.update()` -> `Board.animationCycle()`.
    *   **Transitions**: When the game loop finishes, it sets the state to `GameOverState`, which then handles the game over rendering.

#### 4. Preservation of Existing Structure
*   **Structural Patterns**: No existing structural pattern classes (Facade, Flyweight, etc.) were broken or removed.
*   **Compilation**: The project compiles successfully.
